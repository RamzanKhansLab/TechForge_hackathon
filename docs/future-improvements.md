# Future improvements — outside this MVP

- Account authentication, organizations, key rotation/revocation, expiring sharing, and recoverable report ownership.
- GitHub OAuth and explicitly authorized private repository access.
- GitLab, Bitbucket, and LinkedIn integrations.
- OCR and stronger layout-aware resume parsing.
- Optional LLM-based semantic skill extraction with provenance and reviewable corrections.
- Pull-request and issue analysis; finer contribution attribution and stronger language/framework source inspection.
- Code quality and CI/CD quality evaluation, with a separate sandbox for any future untrusted code execution.
- User-reviewable extraction edits, repository selection, candidate comparison, recruiter dashboards, and team skill analytics.
- A dedicated durable worker tier, distributed rate limiting, cancellation, idempotent creation, asset reconciliation, and automated retention.
- Authenticated resume download/preview with time-limited delivery URLs.

These are intentionally not presented as functioning product features.
